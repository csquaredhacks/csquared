# Investigations

marked as planted. Judges for three tracks score "used the tool on a real issue", and this
folder is the evidence.

Copy this into `YYYY-MM-DD-HHMM-short-name.md`:

```markdown

- **When:** 14:05
- **Planted or real:** real
- **Symptom:** what we saw, and where (Radar / Dash0 / CI / the app)
- **Tool used:** Radar AI investigation | Dash0 Agent0 | Dash0 MCP | Gitar
- **What the tool said:** paste or screenshot
- **Root cause:**
- **Fix:** link to the PR
```
